# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or bypass mechanism in commitguard:

1. Do NOT open a public issue on GitHub.
2. Please report security concerns privately to the maintainers.
3. Include detailed steps to reproduce the issue, including OS, shell, and command arguments.
4. Maintainers will review the report and provide an estimated fix timeline.
